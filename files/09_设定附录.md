## 一、收录口径

| 项 | 说明 |
| --- | --- |
| 抽取范围 | 06_正文_三章.md 定稿全文（不含章末状态登记表） |
| 抽取类别 | 人物、地点、道具、术语 四类 |
| 收录条件 | 只收正文中真实出现的名称，不补正文之外的条目 |
| 释义长度 | 每条不超过 30 字 |
| 首次出现 | 以章号计，第 1 章即视为前文未出现 |
| 同名不同义 | 拆成两条并注明；本稿未出现此类情况 |

## 六、与设定集的差异对照

## 七、附录用法

1. 阅读版 HTML 顶部检索框输入名称，可高亮并跳转到本附录对应条目。
2. 校对时先查本附录，再回正文逐句核对，避免术语漂移。
3. 若本附录与设定集冲突，改附录，不改设定集。
