# 03附_人物关系矩阵说明（判定依据，章末状态口径）

矩阵取值只有四种：信任 / 冲突 / 中立 / 未知。对角线填「—」。判定口径是**第三章章末**的状态，不是第一章的状态。全篇不出现第五位具名人物。

## 一、逐格依据

| 关系 | 取值 | 依据（章末） |
| --- | --- | --- |
| 沈砚 → 沈砚 | — | 对角线 |
| 沈砚 → 阿桉 | 信任 | 他把自己唯一的第二笔写成她的名字；她替他保住了第一格 |
| 沈砚 → 钟叔 | 未知 | 钟叔知道他是谁、知道他写过第二条，却只肯用影子回答；沈砚到最后一刻也没弄清钟叔的钥匙是哪一年交的 |
| 沈砚 → 小满 | 中立 | 他知道纸是她撕的，却不知道她为什么挑那一张；两人没有交换过一句关于木盒的话 |
| 阿桉 → 沈砚 | 信任 | 她账册最后一格写的是他的名字，抄了不止一页 |
| 阿桉 → 钟叔 | 中立 | 她只在他来纸街收旧钟摆铜链时见过他，两人不谈钟 |
| 阿桉 → 小满 | 未知 | 半张纸是从她账册上撕的，撕的人不是她；她至死不知道是谁的手 |
| 钟叔 → 沈砚 | 信任 | 他把绒布借给他擦铜尺，等于承认「你也写过第二条」 |
| 钟叔 → 阿桉 | 中立 | 他知道她在抄，也不拦；抄写不违反规矩 |
| 钟叔 → 小满 | 信任 | 备用的那枚铜钥匙一直放在她布包里，五年没换人 |
| 小满 → 沈砚 | 信任 | 她撕纸是为了给他留一条能找回的路 |
| 小满 → 阿桉 | 中立 | 她替她心疼那本快满的账册，但没有替她做过一次主 |
| 小满 → 钟叔 | 信任 | 钥匙在她这里，说明上一任把最后的事交给了她 |

## 二、关系变化曲线（三章）

| 关系 | 第一章 | 第二章 | 第三章 |
| --- | --- | --- | --- |
| 沈砚 ↔ 阿桉 | 互相观察，谁都不先开口 | 交换代价：她给出竹笔 | 名字互相保管，关系闭合 |
| 沈砚 ↔ 钟叔 | 沈砚问，钟叔不答 | 钟叔在寄存处门外站了一夜 | 交钥匙，师傅与徒弟的位子换了 |
| 沈砚 ↔ 小满 | 未见面（只有半张纸） | 木牌十七与木盒 | 撕纸的人被认出，不追究 |
| 阿桉 ↔ 小满 | 未见面 | 小满替她留门 | 一个不问，一个不说 |
