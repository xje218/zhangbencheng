## 制作方式

依据课堂素材包（9 份素材：世界观设定包、人物小传模板、章节大纲模板、风格样章、连续性检查表、提示词库、封面提示词、验收量表、README）逐步产出，共 9 个步骤：风格基线 → 硬设定 → 人物 → 大纲 → 逐章正文 → 连续性校对 → 索引 → 封面与阅读版 → 自检打包。

- 语言：中文；叙述为第三人称限制视角、短句白描、情绪靠动作承载、设定不靠旁白解释。
- 校对：发现并修订 10 处问题，含 1 处硬设定违反（H1 同日两格并存）、1 处地点错位、2 处事实冲突、1 处术语混用、3 处风格超限、2 处登记失真。
- 未启用能力：文生图接口不可用，封面按封面提示词模板的同构图以矢量绘制，并在制作说明中如实标注；未使用联网检索。
